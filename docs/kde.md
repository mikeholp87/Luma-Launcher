# KDE Plasma shortcuts

Try Register portal shortcut from Luma Settings. If unavailable, open System
Settings → Keyboard → Shortcuts, add Luma Launcher as an application or command,
and bind `luma-launcher --toggle` to Alt+Space. Review existing KRunner and KWin
assignments first; accept reassignment only if you intend to change them.

The installed desktop entry also exposes Luma in application selection. No KDE
configuration files are edited. Choose Super+Space, Ctrl+Space, or another
available combination if you want to preserve existing assignments.

The same desktop-managed command works on X11 and Wayland, subject to the
compositor's focus policy. KDE sessions have not been exercised in this environment.
