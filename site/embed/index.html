This is a browser demo with sample apps. It cannot open anything on your computer, and nothing you type leaves this page.

Try the Luma palette

Type a few letters, use the arrow keys and press Enter. Search is forgiving, so vsc finds Visual Studio Code.

    ↑↓ NavigateEnter OpenCtrl+D PinCtrl+Enter ActionsCtrl+1–9 JumpEsc Clear

    Things to try

    • Press Ctrl+D to pin an app as a favorite.
    • Open an app a few times. The ones you use most move up.
    • Type = 1920 / 16 * 9 or = 200 + 15%.
    • Type g linux launcher or gh luma to search the web.
    • Type screen to find System Settings pages.
    • Type localhost:3000 to open an address.
    • Press Ctrl+Enter on an app for its actions.
